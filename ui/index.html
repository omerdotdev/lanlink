        Transfers

        Disclaimer

        Lanlink is for a network you trust. It listens on TCP port 7420 on all interfaces and may advertise itself with mDNS (UDP 5353). There is no login and no encryption.

        Anyone who can open the join URL can send a file offer, read the shared notes board, and see connected devices. File data is sent only after that device taps Accept. Shared notes are broadcast to everyone. Do not forward port 7420 off your LAN. Do not share passwords on the board. Review file names before accepting. Executables and scripts are blocked.

        Device name and the save folder can be changed only from this computer’s desktop window (localhost). Guests cannot change them over the LAN.

        About

        Lanlink transfers files between devices on the same local network. Discovery and transport stay on the LAN. There is no account and no internet relay.

        Disclaimer

        Use only on a network you trust. Anyone who can reach the join URL may offer a file and see the shared notes board. File bytes move only after that device taps Accept. Notes are broadcast with no encryption. Do not forward TCP port 7420 (or UDP 5353 for discovery) off your LAN. Device name and save folder can be changed only from this desktop app. Programs and scripts cannot be sent. Full notes live in SECURITY.md.
